주문자 조회는 선택기간에 불러온 주문을 대상으로 하며, 서로 다른 동명이인은 별도로 식별하지 않습니다. 제품별 목록은 카페24 상품번호를 우선 기준으로 묶고 옵션별 주문·수량을 집계합니다. 접속 시 최근 30일을 자동 조회하며 직접 날짜를 선택할 수 있습니다(최대 30일 범위). 30일 구간별로 순차 조회합니다. 한도를 초과하거나 API 오류가 발생하면 부분 조회로 표시합니다. 엑셀 내보내기는 한글 호환 UTF-8 CSV이며 현재 검색된 결과만 저장합니다. 고객 연락처와 주소는 표시하거나 저장하지 않고, 조회 결과는 새로고침 시 사라집니다.
